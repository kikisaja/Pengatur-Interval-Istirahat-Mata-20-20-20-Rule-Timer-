# Proyek 80: 20-20-20 Eye Care Timer (Pengatur Interval Istirahat Mata)

Proyek ini adalah aplikasi pemantau interval waktu kerja dan istirahat mata berdasarkan metode kesehatan populer **20-20-20 Rule** (Setiap 20 menit bekerja, istirahatkan mata selama 20 detik dengan melihat objek jarak 20 kaki/6 meter). Dibuat menggunakan **HTML5, CSS3 (SVG Progress Circle), dan Vanilla JavaScript**, sangat cocok untuk media pembelajaran logika timer, *state management* sederhana, dan indikator visual SVG.
